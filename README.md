# Portfolio : Yoann Joseph

Portfolio de Yoann Joseph, programmeur C++ (moteurs de jeu et rendu temps réel),
en 3e année de Bachelor jeu vidéo au Gaming Campus de Bordeaux.

**Voir le site : [yoann16.github.io](https://yoann16.github.io)**

## Ce qui tourne sur la page

La théière et la démo « 1992 » ne sont pas des vidéos : elles sont rendues en direct
par mon moteur de rendu CPU, écrit en C++ et compilé en WebAssembly avec Emscripten.

- `demo/` : le build web du moteur (`renderer.js`, `renderer.wasm`, `renderer.data`)
- `media/` : vidéos et miniatures des projets
- `PORTAGE_WASM.md` : comment le moteur a été porté et comment mettre à jour le build
- `old_version/` : la première version du portfolio, gardée pour comparer

## Technologies

HTML, CSS, JavaScript (sans framework) · C++, SDL3, Emscripten, WebAssembly
